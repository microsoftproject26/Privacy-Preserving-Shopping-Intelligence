**D3 — Feature search: DL39 KEPT, AMENDED.** [PROXY]
Kept: L3 (53→30) adopted statistically (exact FDs, dead/near-constant, |ρ| ≥ 0.95 duplicates, all transferring from n ≥ 1); FS = top 32,768 keys; L0 and L3 trained per family (seed 2026, 6 EFE, USER_HISTORY_L50, catalogue A, full-TRAIN normalizers disclosed); grouped permutation importance; S*; seed-2027 confirmation; one fallback retrain; all rows FEATURE_SEARCH_SCREEN.
Amendments:
1. **Prerequisite:** DATA-05's causality proof (no post-decision event in the window; identical builder for TRAIN and eval) must pass before any FS run. A screen under SESSION_L50 is refused: it would rank features under the wrong input regime.
2. **LR:** the executed v1 peak LR per family (lock-transcribed), common schedule, no calibration. The comparison is within-family, so LR optimality is not required; disclosed.
3. **Groups** (item_tokens is REQUIRED, never permuted; value and its availability flag/mask are permuted jointly; the whole [50] channel column is swapped between decisions): G1 category_tokens; G2 brand_tokens; G3 weekday_tokens; G4 utc_hour sin/cos; G5 log1p_price + price_missing; G6 view gap + prev_gap_unavailable; G7 item age + item_age_unavailable; G8 log1p_segment_elapsed_s; G9 prefix_representative_count; G10 the 3 segment summaries; G11 prev-session gap + prev_session_available; G12a {prev_view_count, prev_session_count, recent_distinct_known_main_categories}; G12b match shares + 2 masks; G12c recent price mean, F-1 difference, recent_price_supported. Fourteen groups; a group is a unit because permutation importance under-reads correlated members individually.
4. **Noise rule:** importance(g) = macro MRR@20(L3) − mean over 3 permutation seeds of MRR@20(L3, g permuted), on the FS VAL users; "within noise" iff the paired-user-bootstrap 95% CI (shared W, 1000, seed 20260926) includes 0. A group is dropped only if within noise for **both** families (conservative in the right direction).
5. **Decision rule (replaces "≤1% CI-consistent", which is infeasible at 10k VAL users, where the half-width alone is ≈1% of MRR, INFERENCE from the 0.111 paired SD):** S* is accepted iff, for the WORSE family, the seed-mean relative drop versus L0 (ratio bootstrapped directly, E7.5) has point estimate ≤ 1.0% **and** 95% CI upper bound ≤ 2.0%; per-seed values reported. Fail → restore the most important dropped group, retrain once (both seeds). Fail again → lock L3 if L3 passes the same rule, else L0. Bounded: ≤ 6 runs per family, ≈5 GPU-h total (INFERENCE).
6. **Outcome discipline:** FS reports publish relative drops, CIs and importances only; absolute MRR levels stay in the receipt until ARCHITECTURE_LOCK, so the screen cannot pre-empt the contest. FS users are excluded from MAIN, CALIB, U_NEW, TB and every panel.
Stop rule: the search ends at the first accepted schema; no descent below S*, no re-opening after the lock.

## OPEN_DISAGREEMENT_RISKS
- N_MAIN 131,072 vs 262,144: a 0.00108 half-width and 97.6% class coverage were judged sufficient; if DATA-05 shows a > 1.5× step cost, only 131,072 remains feasible.
- Full-TRAIN statistics vs pool refit: comparability and single-factor attribution over information-boundary purity; the ≈0.01 z strict-unseen leak is bounded, not zero.
- D3 rule (point ≤ 1%, CI upper ≤ 2%) vs a strict 1% non-inferiority test, which 32,768 users cannot power; a 65,536 FS sample would double screen cost.
- Permutation importance under-reads jointly redundant groups; the S* retrain and one fallback are the safeguard.
- Retiring M04S in favour of U_NEW_VAL selects the few-shot recipe on 5–100 users, then applies it to cold users.
- U_NEW at 32,768 gives ≈0.005 absolute half-width on the unpaired participation gap; adequate for a secondary panel, not for small effects.
