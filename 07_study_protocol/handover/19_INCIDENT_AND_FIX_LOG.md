## How to read this file

- **"DL n" is the decision-log row whose `#` column is n**, not the file line. Duplicate numbers: row 169 exists twice (169b is the Ops row); rows 354–363 exist twice (the second copies are monitoring-only rows from a cron session, DL 377 erratum); row 377 exists twice. I flag those with **[dup]** when it is unclear which copy is meant.
- **Impact on results** has three values: **none** (no result changed; the problem was caught first, or the artefact was never used), **rerun** (something was re-run or replaced), **disclosed** (a result stands but the problem must be stated in the thesis or write-up). I add a short note when time was lost but results were not affected. "Fail-closed" means a guard refused to run and so nothing wrong was produced.
- **I055** is the project's own label for the TEST_ATTEMPTS incident (DL 528). My IDs are INC-nnn.
- Some rows group several small events of the same kind. Rows I could not fully resolve are marked **[AMBIGUOUS]**.
- Experiment IDs (D01, P1-05, X13 and so on) refer to file 18.

## Lessons for future work

1. **Dry-run every irreversible step first, in a scratch folder, with real records.** The two E-step refusals (INC-072, INC-073), the sitting STOP (INC-098), the re-evaluation binding bug (INC-055) and "proofC" (INC-116) all came from analysis or scoring code that disagreed with the registered writers. Test fixtures with tidy values hid each one.
2. **Use the launcher's own spec builder and the registered definitions in every check.** A second implementation of a rule drifts (n_norms, endpoint efe, calibration counts, the DP labels).
3. **Never accept a grid-edge winner.** The FL local-LR screen (x2), the SASRec tuning (lowest LR), the server step (eta 0.001 at the low edge) and the PB100 grid all ended at an edge. Extend the grid under a registered rule before you read further.
4. **Review the tool that selects before its first use, and review the whole sitting script before the single look.** REV-DELTA-02 found a missing registered rule (INC-048); the final-script gate found two blockers (INC-065).
5. **Frozen means frozen: new tree, new hash, new review.** Post-pack edits changed the evaluator hash (INC-039); a server-side patch was unreviewed (INC-047); one amendment was overwritten by a second session (INC-042). Check the log tail and file existence before writing any contract, and keep one owner per file set.
6. **Do not rely on discipline when a guard is cheap.** `H_test.sh` was permission-locked (INC-083); the TEST gates refused wrongly-scoped runs; the TEST_ATTEMPTS file still got a line (INC-105). A tool that "refuses" must be tested on a copy it cannot reach real data from, and the copy must be checked as patched.
7. **Read-only checks belong in preflight, not at launch.** The writable code tree stopped step 8 at launch (INC-108).
8. **Every stop needs an alert.** The Phase-2 chain was stalled 7 h (INC-088); a hung browser session went unseen (INC-102). Give each lane a stop marker the monitor greps, and give each one-shot device run a timeout.
9. **Name the exact artefact and process a check reads or kills.** `LAUNCH_1.json` vs `LAUNCH_0.json` (INC-060), `start_base` vs `start` (INC-065), `pkill` matching its own shell (INC-069), a SIGSTOPped `sleep` child (INC-095). Use anchored patterns and pause by job, not by group.
10. **Measure before adding concurrency, and say the real state.** GPU time-slicing meant more jobs did not help (INC-087); shared throughput rules are not numeric rules, so register any deviation (INC-041).
11. **A diagnosis is worth more than a bigger sweep.** The FedAdam tau finding (X01) explained weak federated arms across benchmarks and REES46 in one measurement; the first full grid was dropped for a lean plan (X02).
12. **Say what a baseline can and cannot show.** The realism audit (INC-043) and the D1 diagnostic (INC-075) turned "FL cannot help" into "under the registered recipe"; later runs showed the value depends on how much data the server has (X12, X14).
13. **Keep time, numbers and claims honest.** Take times from `date -u` (INC-001, INC-120); compute numbers instead of recalling them (INC-018); check public claims against the registered source (INC-054, INC-118); mark inference as inference and correct it in a row (INC-109).
14. **Work must survive a cut.** Spend limits and quota cuts hit about ten times (INC-121). State in files, packets, write-once records and resumable lanes meant nothing was lost. Always require the hand-back file (INC-086).
15. **Shared account hygiene.** One account for the whole team: do not touch unknown processes (INC-074), keep credentials outside temp folders (INC-110), never install into shared environments (INC-026), and ask the owner before touching a personal device (INC-094). Never route around a permission refusal: the classifier blocks (INC-056, INC-084) and the refused shell appends (INC-115) were each resolved by asking the owner.
